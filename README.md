# DanceTalk
춤으로 연결되는 우리의 이야기

댄서들이 정보를 공유하고 소통할 수 있는 댄스 커뮤니티입니다.

## 개발 배경
댄스 강사로 활동하며 경험한 정보 공유와 팀원 모집의 필요성을
바탕으로 제작했습니다.

## 주요 기능
- 회원가입, 로그인, 회원정보 수정 및 탈퇴
- 카테고리별 게시글 조회
- 게시글 및 댓글 작성, 수정, 삭제
- 게시글 및 댓글 추천
- 검색 및 페이징

## 기술 스택
Java, Spring Boot, Spring Security, JPA, MySQL
Thymeleaf, HTML, CSS, JavaScript, Bootstrap
